# World Audition Lab - public preview candidate

This folder is a public-safe, **unverified runtime candidate** for the independent World Audition Lab. It is separate from production Museum of Me and the eight replacement experiments.

21 source-backed project identities, 105 **proposed** opportunities, and 20 source-available previews. INFINITUM is source-only and intentionally not launchable. Original project source archives are **not published**. Source hashes in the metadata refer to locally retained private originals.

The original Lab interface is preserved with a bounded public transport adapter. Only the 20 executable preview files are repacked as seekable, uncompressed ZIP_STORED per-world payloads; a scoped service worker serves them as same-origin URLs. This requires HTTPS or localhost, service-worker support, and WebGL2. The UI supports only one active iframe at a time.

**Proof:** static payload manifest and JS syntax may pass before commit. Real WebGL interaction, 20 complete playthroughs, mobile GPU and sustained performance must be independently verified; until then do not call this a released playable collection.

The existing repository's museum Pages workflow is not a valid publication proof for this folder and must not be triggered without correction.
